ABRIR LOCALMENTE
Serví esta carpeta por HTTP; fetch no funciona abriendo el HTML con doble clic.
Si Python está instalado: python -m http.server 8000 --bind 127.0.0.1
En esta computadora también podés usar el Python incluido con Codex:
& 'C:\Users\ciros\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m http.server 8000 --bind 127.0.0.1
Abrí http://127.0.0.1:8000/. Ctrl+C detiene el servidor de pruebas.
El sitio público no requiere Python, Node, backend ni compilación.

ARCHIVOS
index.html, cases.html, accesorios.html: páginas y plantillas.
styles.css: diseño responsive compartido.
script.js: carga/validación, búsqueda, carrito y mensaje de WhatsApp.
productos.json: única fuente compartida de productos.
images/: imágenes del sitio.
_headers: lectura del JSON desde el panel local y control de caché en Cloudflare.

DATOS
id: entero positivo único, no reutilizar al eliminar.
nombre, categoria (cases/accesorios), descripcion, imagenUrl, modelos.
precio: entero positivo; null significa pendiente SOLO en productos no publicados.
imagenUrl: ruta relativa o HTTPS; cadena vacía permitida si no está publicado.
modelos: lista de compatibilidades; [] para producto sin selector.
estado: borrador, publicado, pausado o archivado.
disponibilidad: activo o agotado; nunca cantidades exactas de existencias.
Solo publicados aparecen; un agotado se muestra sin botón de agregar.
Un publicado requiere precio, imagen válida y descripción.
El JSON es público incluso para borradores: no introducir notas privadas ni tokens.

Recomendado: Cloudflare Pages. Dominio previsto: cases4you.com.py.
Build exit 0, salida . y main como rama de producción.
Subir solamente el contenido de esta carpeta; nunca la carpeta padre ni admin-local.
Los pasos de dominio y accesos están en ../admin-local/HOSTING-Y-DOMINIO.md.

COMPROBAR EL FLUJO
- Inicio y categorías vacíos mientras todos los reales sean borradores.
- Completar una ficha en el panel y elegir publicado; comprobar la vista previa.
- Tras publicar y finalizar el despliegue, elegir modelo y agregar al carrito.
- Agregar dos modelos del mismo producto: deben quedar en filas distintas.
- Navegar, recargar, modificar cantidades, revisar el total y el mensaje.
- Marcar agotado/pausado y recargar: se retira del carrito con aviso.
- La lupa busca por nombre, descripción y modelo en la página actual.
- Instagram aparece junto al carrito, con el perfil cases4you.py existente.
- Probar Tab, Escape y anchos de celular. No se envía WhatsApp automáticamente.
